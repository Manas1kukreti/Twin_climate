# ClimateTwin

A lightweight AI-driven local climate digital twin inspired by
methodological principles from
[Aurora](https://www.nature.com/articles/s41586-025-08897-0) (Nature, 2025)
and [CREDIT](https://www.nature.com/articles/s41612-025-00932-x)
(npj Climate and Atmospheric Science, 2025).

ClimateTwin does **not** reproduce either system. It adapts selected
research ideas at a localized, computationally feasible scale for a
college-level research project.

## Quick Start

```bash
# Create a virtual environment
python -m venv .venv
# Activate (Windows)
.venv\Scripts\activate
# Activate (Unix)
source .venv/bin/activate

# Install dependencies
pip install -e ".[dev]"

# Run tests
pytest
```
